## 📌 Про проєкт

Програма повністю автоматизує цикл підготовки тестів для навчальних організацій, акредитованих за стандартом **EASA Part 147**: від завантаження переліку питань до готових `.docx`-файлів, що відповідають усім нормативним вимогам.

### Підтримувані категорії

| Категорія | Опис |
|-----------|------|
| **B1.1** | Авіаційний механік — газотурбінний літак |
| **B1.3** | Авіаційний механік — газотурбінний вертольот |
| **B2** | Авіаційний механік — авіоніка |

---

## ⚙️ Функціональність

- 📥 **Імпорт питань** — зчитує питання з `.docx`-таблиць, включно з вбудованими зображеннями та формулами
- 📊 **Норми питань** — завантажує таблицю норм: скільки питань з кожного розділу має потрапити до тесту
- 🎲 **Генерація варіантів** — випадковий відбір з гарантованим дотриманням норм та відсутністю повторень між варіантами
- 📄 **Експорт у Word** — окремі файли для варіанта тесту та ключа відповідей; при повторній генерації файли не перезаписуються, а отримують суфікс `_002`, `_003` тощо
- 📋 **Журнал генерацій** — зберігає дату, категорію, кількість варіантів і шлях до папки з результатами
- 🌙 **Темна / світла тема** — перемикання в один клік

## 🗂️ Структура проєкту

```
Part 147/
├── src/
│   ├── gui.py              — Графічний інтерфейс (CustomTkinter)
│   ├── database.py         — Шар доступу до бази даних (SQLite3)
│   ├── parser.py           — Парсинг Word-файлів з питаннями
│   ├── generator.py        — Алгоритм генерації варіантів
│   ├── exporter_docx.py    — Формування вихідних .docx
│   ├── quota_loader.py     — Завантаження таблиці норм
│   └── seed_db.py          — Масовий імпорт модулів
├── data/
│   ├── questions.db        — База даних SQLite
│   └── history.json        — Журнал генерацій
├── output/                 — Вихідні тести та ключі відповідей
├── requirements.txt
└── README.md
```

## 🚀 Запуск

**Вимоги:** Python 3.10+

```bash

git clone https://github.com/PolinaDerevetska/diploma_project.git
cd diploma_project

# 2. Встановити залежності
pip install -r requirements.txt

# 3. Запустити
```
