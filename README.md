## Про проєкт

Настільне програмне забезпечення для автоматизації формування тестових варіантів у навчальних організаціях, що працюють за стандартом **EASA Part 147**.

Програма дозволяє:
- імпортувати банк питань із Word-документів (`.docx`), включно з питаннями, що містять формули та зображення
- завантажувати таблиці квот питань за розділами для категорій **B1.1**, **B1.3**, **B2**
- автоматично генерувати унікальні тестові варіанти з дотриманням квот
- експортувати готовий тест та ключ відповідей у формат **Microsoft Word**

## Структура проєкту

```
Part 147/
├── src/
│   ├── gui.py            # Графічний інтерфейс (tkinter)
│   ├── generator.py      # Алгоритм генерації тестових варіантів
│   ├── parser.py         # Парсинг Word-документів з питаннями
│   ├── quota_loader.py   # Завантаження таблиці квот
│   ├── database.py       # Робота з SQLite базою даних
│   ├── exporter_docx.py  # Експорт тесту у формат .docx
│   └── exporter_pdf.py   # Експорт у PDF (резерв)
├── main.py               # Точка входу
├── requirements.txt      # Залежності
└── README.md
```
